В данной программе не реализованы этапы проверки (вводимой информации от пользователя) на корректность (кроме проверок на ввод доступных операций и критериев поиска/сортировки).
Все типы вводимых полей для объекта Товар являются строковыми, кроме цены. Все строковые поля принимают информацию через getline.
Дату необходимо вводить строго в указанном формате DD.MM.YYYY
Реализация проверок на корректность для вводимых полей рассматривается как дальнейшее продолжение данного проекта. 

This program does not implement the stages of input validation (user-provided information) for correctness
(except for checks on the input of available operations and search/sort criteria). 
All types of input fields for the Product object are string fields, except for the price. 
All string fields accept information through getline. The date must be entered strictly in the specified format DD.MM.YYYY. 
Implementing validation checks for input fields is considered a further continuation of this project.
